# Portfolio AZ-104 – Administrateur Microsoft Azure
#  Bienvenue sur mon portfolio consacré à l’administration de Microsoft Azure.

Ce dépôt GitHub présente mon parcours d’apprentissage et mes travaux pratiques dans le cadre de la préparation à la certification Microsoft Azure Administrator (AZ-104).

# Objectifs

* Apprendre à administrer les services Microsoft Azure.
* Gérer les identités et les groupes avec Microsoft Entra ID.
* Administrer les ressources de stockage.
* Déployer et gérer les machines virtuelles.
* Configurer les réseaux virtuels.
* Surveiller et sauvegarder les ressources Azure.
* Développer mes compétences avec Azure CLI et PowerShell.
